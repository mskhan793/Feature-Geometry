# 04 — Gaussian mixtures and multimodality

**Status:** Planned.

**Research question:** When does a class require multiple Gaussian components rather than one prototype or one Gaussian?

**Starting controls:** Two distinct Gaussian clusters sharing one class label. Compare cosine/Euclidean prototype, class-conditional Gaussian, and GMM decisions. Use disjoint training/test sets.

**Primary reference:** Cao et al. (ICML 2026), §4.2–4.3.

**Reporting:** means, covariances, mixing weights, components selected, log-likelihood, accuracy, calibration, and failure cases.
