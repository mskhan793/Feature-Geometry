# 01 — NCM and metric learning

**Status:** Planned.

**Research questions:** When is one class mean sufficient? How do within-class spread and direction affect Euclidean/cosine NCM? What changes with learned Mahalanobis metrics?

**Starting controls:** 2D Gaussian classes with fixed mean separation and varying within-class covariance.

**Primary reference:** Mensink et al. (2013).

**Reporting:** seed, n per class, separation, covariance, classifier, held-out accuracy, limitations.
