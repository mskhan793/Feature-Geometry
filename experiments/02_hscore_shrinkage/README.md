# 02 — H-score and covariance shrinkage

**Status:** Planned.

**Research questions:** When is H-score unstable? Does Ledoit–Wolf shrinkage improve score estimation? Does random projection change source-model rankings?

**Starting controls:** n << d synthetic representations; compare unregularized covariance, shrinkage, and projection under fixed labels.

**Primary reference:** Ibrahim et al. (2023).

**Reporting:** sample count, embedding dimension, covariance estimator, shrinkage coefficient, projection seed, score, downstream frozen-classifier accuracy.
